# dotfiles

This repo contains my dotfiles as managed by chezmoi.

It covers everything under `$HOME`, on all my machines (work and personal). On my Arch desktops, the system side (packages, `/etc`, system services) lives in [arch-config](https://codeberg.org/Crocmagnon/arch-config). CLI tools wanted everywhere come from mise here; tools only needed on Arch, or that mise cannot install, come from pacman there.
